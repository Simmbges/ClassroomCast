### 附加轮：UI 高 DPI 修复与"复制 IP"（已执行）

用户反馈高 DPI 屏（200% 缩放）上部分按钮文字显示不全，并要求增加复制老师 IP 的按钮。已验证：

1. **根因定位**（DPI 探针实测）：.NET 8 WinForms 在高 DPI 进程中创建控件时不会自动执行 96→DPI 的初始缩放（`AutoScaleMode.Font/Dpi` 乃至显式 `PerformAutoScale()` 均不生效），字体按真实 DPI 变大而控件尺寸停留在 96 基线，导致文字溢出被裁。
2. **修复方式**：新增 `DpiScale.ScaleChildren` 手动缩放辅助（按 `DeviceDpi/96` 递归缩放布局树；AutoSize 控件只缩位置、单行输入类只缩宽度、ListView 列宽单独处理），布局数值统一按 96 DPI 基线书写。
3. **复验**（打包后 exe，200% 缩放屏）：主窗体、按钮、列表、日志全部文字完整清晰；"复制 IP"按钮点击后剪贴板内容为 `10.201.79.68`（与所选网卡一致）；"在线学生（N）"人数并入分组框标题。
4. **回归**：开始共享 → 状态"共享中｜编码 13 FPS"；测试客户端连入 10 秒收 128 帧（约 12.8 FPS）；名单实时显示"学生甲"并随断开更新。✅

## 三、性能实测（本机，单机回环，供参考）

- 采集+编码（1440×900，JPEG 质量 70）：**平均 19.5–25.1 ms/帧**（多次运行），单帧最大 33–41 ms，**平均 111 KB/帧** → 单客户端场景估算可支撑 40–51 FPS。
- 1080p 及多屏拼合时帧更大、耗时更长；60 FPS 目标在本机未达到（预期内，UI 如实显示）。
- 带宽估算公式：`111 KB × 帧率 × 学生数`（详见《使用说明》带宽表）。

> 以上为单机数据，**不同硬件差异较大**，请以软件界面显示的"编码 X FPS"为准。

## 四、未验证项（无多机条件，需要你在实际教室环境确认）

1. **多台真实电脑跨网传输**：本测试全部为本机回环/本机 IP 自连。跨机器需按《使用说明》配置防火墙后用两台电脑实测（步骤：老师端开始共享 → 学生端输入 IP 连接）。
2. **真实网络下的延迟与卡顿表现**：回环测试无法反映真实交换机/Wi-Fi 的影响。
3. **多人并发规模上限**（>4 连接）：逻辑上无上限（连接数上限 100），但带宽才是瓶颈，建议先小规模试跑。
4. **观看窗口"不抢焦点"**：代码使用 `ShowWithoutActivation` 打开观看窗，自动化验证未覆盖焦点行为，请人工确认：学生打字时连接成功，输入焦点不应被观看窗抢走。
5. **防火墙"允许访问"弹窗**：本机测试未触发（连接为非回环但未跨网段），实际教室中首次共享请留意弹窗并勾选"专用网络"。
6. Windows 10 旧版本（本机为 Win11 24H2）：.NET 8 官方支持 Win10 1607+，理论上兼容，未实测。

## 五、已修复的问题（开发过程中发现并解决）

- `NetworkStream.WriteTimeout` 对异步写无效 → 发送改为同步写 + 专用线程，慢客户端可被写超时踢除。
- 端口占用测试自身的绑定顺序错误（测试问题，非产品问题）。
- PowerShell 中文脚本需 UTF-8 BOM。
- 若干编译期 API 误用（ListView.ReadOnly、Thread.Joinable 等）。
