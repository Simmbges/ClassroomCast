# 使用说明

## 一、开始前的准备（一次性）

1. 确认老师电脑和所有学生电脑连接**同一个局域网**（同一交换机/同一 Wi-Fi，或可互通的教学网段）。
2. 建议给老师电脑设置**固定 IP**（或由机房网管做 IP-MAC 绑定），避免 IP 变化导致学生连不上。
3. 防火墙放行（老师电脑只需做一次，二选一）：
   - **方式 A（推荐）**：第一次点"开始共享"时，Windows 会弹出"是否允许访问网络"提示，勾选**"专用网络"**后点"允许访问"即可。
   - **方式 B（提前配置）**：以管理员身份运行 PowerShell，执行本软件 `scripts` 目录下的 `firewall.ps1`（放行 TCP 9527 端口）。
     手动执行等价命令：
     ```bat
     netsh advfirewall firewall add rule name="教室屏幕共享" dir=in action=allow protocol=TCP localport=9527
     ```
   - **不需要关闭防火墙**，也不要放行整个程序目录之外的内容。

> 如果机房网络被划为"公用网络"，方式 A 的弹窗可能不会出现或勾选无效。此时让网管把该网络改为"专用网络"，或用方式 B 的命令把 `profile=private,domain` 改为 `profile=any` 后再执行。

## 二、老师端（Server）操作

1. 双击运行 `ClassroomScreenShare.exe`，选择 **Server 老师端** 页签。
2. **本机地址**：下拉框会列出本机所有可用的局域网 IPv4 地址，格式为 `网卡名（网卡型号）— IP`。
   - 一般选"以太网"或"WLAN"开头的那个地址。
   - 列表里不会出现 127.0.0.1 等无效地址；如果不确定选哪个，可以把显示的 IP 告诉学生（或投在黑板上）。
   - 点 **复制 IP** 可把当前选中的 IP 复制到剪贴板，直接发到班级群或投屏即可。
   - 换了网络环境后点 **刷新**。
3. **端口**：默认 9527，一般不用改；提示"端口被占用"时改成其他数字（1024–65535）即可。
4. **帧率 FPS**：默认 15。教室场景 10–15 FPS 已经流畅；机器好、网络好可试 30。**60 FPS 对普通机器和百兆网络压力很大，不保证能达到**——界面上的"编码 X FPS"就是实际达到的帧率，请以它为准。
5. 点 **Server - 开始共享**。状态栏显示"共享中｜编码 X FPS｜已发送 X MB"，其中"编码 X FPS"是每秒刷新的实际值。
6. **在线学生**区域实时显示已连接学生的姓名、连接时间和在线人数。学生加入、主动断开或意外掉线都会自动更新；同名学生显示为 张三、张三(2)……
   - 点分组框右上角的 **导出名单**，选择保存位置后即可把当前在线学生导出为 CSV 文件（含序号、姓名、连接时间），Excel/WPS 双击直接打开不乱码；文件名默认带导出时间。当前没有学生在线时会给出提示。
7. 运行中可以随时用帧率下拉框**切换帧率**（立即生效，无需重启共享）。
8. 点 **Server - 停止共享**：画面停止，学生端会显示"老师已停止共享，等待老师重新开始…"，学生连接保持，再次点"开始共享"学生画面自动恢复。关闭软件窗口则彻底结束并断开所有学生。

## 三、学生端（Client）操作

1. 双击运行同一个 `ClassroomScreenShare.exe`，选择 **Client 学生端** 页签。
2. 输入**姓名**（显示在老师端名单里，仅用于标识，不用注册）和**老师 IP**（老师端界面显示的地址，形如 `192.168.1.100`），端口与老师端一致（默认 9527）。
3. 点 **Client - 连接**：
   - 连接成功后自动弹出观看窗口，老师一开共享就能看到画面。
   - 观看窗口可以**随意调整大小、最小化、移动**，画面始终按原始比例缩放；**不会全屏、不会锁你的键鼠、不抢焦点**，你可以一边看一边操作自己的软件。
4. 点 **Client - 断开**（或直接关闭观看窗口）即停止观看；想再看时重新连接即可。
5. 常见提示的含义：
   - "老师已停止共享，等待老师重新开始…"：等老师再次开始即可，不用重连。
   - "与老师电脑的连接已断开"：老师退出了软件，或网络中断；稍后重新连接。
   - 弹窗"连接超时 / 无法连接到老师电脑"：检查 IP 是否输对、老师是否已开始共享、防火墙是否放行。

## 四、常见问题排查

| 现象 | 排查顺序 |
|---|---|
| 学生"连接超时/无法连接" | ① 学生 ping 老师IP（`ping 192.168.x.x`）是否通；② 老师端是否点了"开始共享"；③ 老师端防火墙是否放行 9527；④ 两台电脑是否在同一网段（IP 前三段是否一致） |
| 连上但黑屏/无画面 | 老师是否处于"停止共享"状态？等待或让老师点"开始共享" |
| 老师端列表人数与学生实际不符 | 网络瞬断的学生约 20 秒内会被自动检测并移除；也可在学生端点断开重连刷新 |
| 画面卡顿 | 降低帧率（10 或 5）；老师端状态栏"编码 X FPS"低说明老师机器编码吃力，可关闭其他大程序；多学生卡顿多为带宽不足（见下） |
| 启动共享提示"端口被占用" | 更换端口（老师端与学生端要一致），或关闭占用 9527 的程序 |
| 学生 IP 输错格式 | 程序会提示"IP 地址格式不正确"，请按 `x.x.x.x` 格式输入 |

## 五、带宽参考（按实测数据估算）

免安装版在本机实测：1440×900、JPEG 质量 70 时约 **111 KB/帧**。带宽消耗 ≈ 帧大小 × 帧率 × 学生数：

| 场景 | 约需带宽 |
|---|---|
| 1 名学生，15 FPS | ≈ 13 Mbps |
| 10 名学生，15 FPS | ≈ 130 Mbps |
| 30 名学生，15 FPS | ≈ 390 Mbps |

**千兆局域网（网线）**可支撑全班规模；**百兆网络或 Wi-Fi 覆盖的教室**建议把帧率降到 5–10，或减少同时观看人数。每个学生的带宽消耗相同（服务器向每个学生各发一份）。

## 六、明确不做的事

本软件不包含：声音共享、远程控制、锁屏/控屏、文件传输、聊天、录像、云服务、账号系统。请勿用作监控用途。
